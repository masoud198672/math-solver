# حل‌کن ریاضی (Math Solver)

ابزار حل مرحله‌به‌مرحله‌ی معادلات درجه‌ی اول و دوم به زبان فارسی، برای دانش‌آموزان.

سایت: https://masoud198672.pythonanywhere.com

## امکانات
- حل معادله‌ی درجه‌ی اول و دوم با نمایش مراحل (ضرایب، دلتا، فرمول ریشه‌ها)
- پشتیبانی از ورودی معمولی مثل `2x^2 - 5x + 2 = 0`
- نمایش پیام ساده وقتی معادله ریشه‌ی حقیقی ندارد

## ساخته‌شده با
Python، Flask، SymPy

## فایل‌ها
- `flask_app.py`: نسخه‌ی وب (سایت اصلی)
- `templates/index.html`: صفحه‌ی سایت
- `app.py`: نسخه‌ی اولیه با Streamlit
